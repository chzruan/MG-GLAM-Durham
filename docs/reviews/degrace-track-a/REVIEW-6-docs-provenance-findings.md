# REVIEW 6: documentation, provenance and repository hygiene

Branch `degrace-track-a` (15 commits, `cz..degrace-track-a`, merge base 69c9261).
Scope: `docs/degrace_companion_implementation_plan.md`, `DEGRACE-companion/README.md`,
`2LPTIC_Gui/README.md`, `2LPTIC_Gui/fml_intel_port/APPLY.md`, `test/precise_z/README.md`,
`.gitignore`, `DEGRACE-companion/.gitignore`; `AGENTS.md` as the rule book; writers,
CLIs, test scripts and the on-disk pilot directories read only to test documentation
claims. Read-only review, 2026-10-17; nothing was built or run except `git`, `ls`, `du`,
`cmp` and one `sacct` query. `gen_inputs.py --check` was refused by the permission
layer and was not re-run, so the S2 numbers stand as the author's.

## 1. Summary

The plan's section 16 log, the pilot records and the storage arithmetic are accurate:
every cited hash exists and touches what is claimed, the ΛCDM pilot numbers (wall time,
cores, MaxRSS, CPU efficiency, 9.1 GB, 201 MB planes, 17 catalogues) reproduce from
`sacct` and the run directory, and the `.meta` key sets of LensPlanes, Subsample, fR_halo
and deltaL match the item specs (I2, I9, I10, I7). The documentation fails where the
plan's *normative* sections were written before the code and never reconciled: the
section 7 flag table gives names and defaults the code does not have (an f(R) run set up
from it gets no `fR_halo` files), section 3 claims a velocity-epoch consistency that the
legacy BDM catalogue breaks by 0.5–1 %, and the I8 interlacing rule is neither
implemented nor recorded as dropped although the running f(R) pilot is in the regime
where the rule applies. The status header, checklist and test tables are stale, the
test suites depend on untracked input files, and the campaign provenance required by
`AGENTS.md` is scattered across a gitignored run directory, the ECOSMOG README and the
plan rather than recorded in one place.

Recommendation: **ready after the listed fixes**. All three Majors are documentation
corrections (plus a decision on whether M2/M3 become code follow-ups); none blocks the
code merge itself.
